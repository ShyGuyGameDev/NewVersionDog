NewVersionDog camera + Mac YOLO deploy notes
============================================

Pi role: raw camera only (no torch / ultralytics on this board).
Mac role: run YOLO11n overlays via dog_yolo_mac.py

Pi files:
  /home/pi/system/cam.py
  /home/pi/system/camconfig.json
  /home/pi/system/srv/index.html

Mac file:
  YOLOv8 Working/dog_yolo_mac.py

Pi restart:
  sudo systemctl restart camera

Mac run:
  cd "YOLOv8 Working"
  source ../.venv/bin/activate
  python dog_yolo_mac.py

Safe Pi shutdown before cutting power:
  ssh pi@10.1.1.146 'sudo shutdown -h now'
